# Создание фамильяров

Чтобы создать **фамильяра**, Хампердинк (или другой **биомант**) нуждается в одном из компонентов уникального монстра, капле крови персонажа игрока и плате, равной **20-кратному уровню игрока в зм**. Через **24 часа фамильяр** создан и немедленно связан с персонажем, от которого была пожертвована кровь. Когда этот персонаж сотворяет [[Поиск фамильяра]], он может выбрать этого **фамильяра** вместо одного из обычных вариантов

# Индивидуальные спутники

Эти созданные **фамильяры** идеально подходят для обучения [[Укротитель|укротителями]]. Существо, созданное таким образом, может быть приручено его связанным [[Укротитель|укротителем]] **без проверки характеристики**. После приручения существо больше не может быть призвано [[Поиск фамильяра|Поиском фамильяра]] и становится **индивидуальным спутником**

**Общая стойкость.** Когда **индивидуальный фамильяр** становится [[Укротитель#Карманный фамильяр|спутником]], он получает **Бонусные улучшения укротителя**, перечисленные в соответствующем разделе, **без необходимости** для [[Укротитель|укротителя]] **тратить 1 из своих улучшений**. Более того, по мере роста могущества [[Укротитель|укротителя]] его связь с **индивидуальными спутниками** укрепляет их. Когда персонаж достигает **3-го**, **5-го**, **11-го** или **17-го уровня укротителя**, каждый из его **индивидуальных спутников** получает **1 дополнительную Кость Хитов**. Когда это происходит, **максимум хитов спутника** увеличивается на **бросок Кости Хитов + модификатор Телосложения спутника** (минимум 0). Эти увеличения также применяются задним числом, если [[укротитель]] получает **индивидуального спутника** после того, как достиг этих уровней

**Индивидуальные улучшения.** Эти созданные существа получают новые способы извлекать выгоду из улучшений, предоставляемых умением [[Укротитель|укротителя]] [[Укротитель#Тренер монстров|Тренер монстров]]. Когда [[укротитель]] получает уровень, он может выбрать предоставление этим существам улучшения из специфичных для существа вариантов, перечисленных в разделе его **фамильяра**, вместо обычных, доступных всем существам, приручённым [[Укротитель|укротителем]]
