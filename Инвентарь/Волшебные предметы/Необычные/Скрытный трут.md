# Скрытный трут [Furtive Firestarter]

Чудесный предмет, **необычный**
**Рекомендованная стоимость:** tbd
**Источник:** «Homebrew»

Этот искусно изготовленный набор из кремня и огнива несёт малые руны, выгравированные по бокам обеих частей. Когда набор используется для поджигания горючего материала, получившееся пламя испускает **яркий свет** в радиусе **10 футов**, **не испускает тусклого света** и **не производит дыма**. Находясь в пределах **30 футов** от пламени, созданного таким образом, пользователь может произнести командное слово, чтобы **мгновенно погасить** пламя
